# 04 Design Brief

## Purpose

Set the visual and interaction direction for a one-page sponsor-facing website that communicates credibility, social impact, and clear pathways to support Cryptita Plays programs, including ACIS.

Related docs: [Master Context](./00-master-context.md), [Information Architecture](./03-information-architecture.md), [Technical Specification](./05-technical-specification.md), [Testing and QA](./07-testing-and-qa.md)

## Design Intent

- Present Cryptita Plays as trusted, community-driven, and education-first.
- Balance heart-led storytelling with implementation clarity.
- Make sponsorship and partnership actions obvious at every key decision point.

## Brand and Messaging Expression

- **Tone:** warm, credible, practical, community-centered.
- **Positioning:** bridging Web3 education and social impact.
- **Narrative principle:** people first, education over hype, long-term support over one-off campaigns.

## Visual Direction

- Clean, modern layout with strong content hierarchy.
- Human-centered imagery showing real learners, communities, and outreach contexts.
- Friendly but professional UI style suitable for institutional and sponsor audiences.
- Consistent spacing and typography to support skimmable reading.

## Slide-to-Section Experience Mapping

- Cover -> Hero with mission statement and primary CTA.
- Who We Are + Problem -> trust and urgency section pair.
- Our Approach -> concise model explanation with key principles.
- Core Programs + Learning Materials -> card-based program and resource blocks.
- ACIS + How ACIS Helps -> featured sponsorship spotlight section.
- Impact + Partners -> proof and credibility strip.
- Why We Do This + What’s Next -> mission and roadmap.
- Join + Thank You -> final conversion and relationship-oriented close.

## Core Components

- Sticky header with anchor navigation and persistent CTA.
- Hero section with headline, supporting copy, and action button.
- Problem/approach split layout (2-column desktop, stacked mobile).
- Program cards for Mini-Library, Replenish, and Web3 seminars.
- Educational materials list with icon support.
- Featured ACIS module with eligibility and support details.
- Impact metrics and narrative panel.
- Partner logo grid by category (educational, community).
- Multi-option "Get Involved" CTA cards.
- Contact/footer block with email, socials, and phone.

## ACIS Feature Requirements

- Visually distinct section to emphasize sponsor relevance.
- Include concrete details:
  - Monthly educational assistance
  - School supplies and learning materials
  - Mini-Library resource access
  - Up to 5 student beneficiaries per Mini-Library area
- Include direct CTA: `Support ACIS Scholars`.

## Responsive and Accessibility Requirements

- WCAG AA contrast targets.
- Keyboard navigable interactive elements.
- Touch-friendly navigation and CTA sizing.
- Clear focus states and reduced-motion-friendly transitions.
- Descriptive alt text and accessible label patterns for forms/buttons.
- Reduced-motion friendly transitions.

## Deliverables for Implementation

- Low-fidelity wireframe.
- High-fidelity responsive mockup (mobile, tablet, desktop).
- Component inventory with states (default, hover, focus, active).
- Lightweight design tokens (color, type scale, spacing, radius).
- Content placement notes aligned to the approved slide flow.
