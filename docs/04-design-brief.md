# 04 Design Brief

## Purpose

Establish visual and interaction direction for the sponsor-facing one-page site.

Related docs: [Information Architecture](./03-information-architecture.md), [Technical Specification](./05-technical-specification.md), [Testing and QA](./07-testing-and-qa.md)

## Design Goals

- Convey trust, warmth, and professionalism.
- Highlight community impact without visual clutter.
- Keep CTA pathways obvious and consistent.

## Brand Expression

- Voice: empathetic, credible, action-oriented.
- Style: modern, clean, human-centered.
- Imagery: authentic community photos over stock-like visuals.

## UI Direction

- Mobile-first responsive layout.
- High-contrast typography and button states.
- Reusable components for cards, stats, and CTAs.

## Suggested Component Set

- Header with anchor nav and CTA.
- Hero block with mission statement.
- Program cards.
- Impact metrics strip.
- Partnership tiers/options.
- Contact block + footer.

## Accessibility Requirements

- WCAG AA contrast targets.
- Keyboard navigable interactive elements.
- Alt text for meaningful images.
- Reduced-motion friendly transitions.

## Deliverables

- Low-fidelity wireframe.
- High-fidelity responsive mockup.
- Lightweight style token list (colors, type scale, spacing).
- Component notes for implementation.
