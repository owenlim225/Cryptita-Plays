# 12 Project Management

## Purpose

Track execution rhythm, responsibilities, and reporting.

Related docs: [Implementation Plan](./06-implementation-plan.md), [Risk Register](./10-risk-register.md), [Decision Log](./11-decision-log.md)

## Working Model

- Lightweight weekly planning and status review.
- Shared task board with prioritized backlog.
- Clear owner for each deliverable.

## Roles (Example)

- Product Lead: scope and stakeholder alignment.
- Design Lead: UX/UI quality and brand fit.
- Engineering Lead: implementation and reliability.
- Content Lead: messaging and approvals.

## Milestones

- M1: Requirements and content approval.
- M2: UI implementation complete.
- M3: QA pass and launch readiness.
- M4: Production launch and monitoring baseline.

- Major changes require product + engineering sign-off.
